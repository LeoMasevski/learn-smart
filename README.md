# learn-smart
LearnSmart je spletna aplikacija za personalizirano učenje, ki s pomočjo AI prilagaja učne vsebine različnim učnim tipom (vizualni, slušni, kinestetični). Sistem vključuje adaptivne kvize, spaced repetition priporočila ter dashboarde za študente in profesorje za spremljanje napredka in analitiko učenja.
